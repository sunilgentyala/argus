How it works

The closed-loop pipeline

Four specialized agents running in a continuous revision loop — not a static probe list.

  Target LLM / Pipeline
          |
          v
  ┌───────────────────────────────────────────────┐
  │              Orchestrator                       │
  │                                                  │
  │   Planner ──> Attacker ──> Evaluator            │
  │      ^             |             |               │
  │      |             v             v               │
  │      └──── Revision <── Findings + CVSS         │
  │                                    |             │
  │                               Reporter           │
  └───────────────────────────────────────────────┘
          |
          v
    SARIF + JSON reports  ──>  CI/CD / GRC tooling
🧠

Planner

Claude Opus reasoning model formulates and revises attack strategy in real time using live target behavioral signals and cross-session episodic memory.

⚔️

Attacker

Synthesizes novel payloads via embedding-space diversity constraint — avoids coverage collapse and ensures the target's full attack surface is exercised.

🔬

Evaluator

Three-layer detection: semantic proximity against a confirmed-attack embedding space, LLM-as-judge panel with configurable quorum, and behavioral trace analysis.

📊

Reporter

Generates SARIF v2.1 and structured JSON reports. CVSSv4.0 vectors computed for every finding, mapped to all applicable global regulatory frameworks.

Installation

Get started

Install once, scan any supported target with a single command.

● Install 
pip install -e .
Requires Python 3.11+. API key resolved from env or --api-key flag.
● Anthropic (Claude) 
argus scan \
  --target anthropic \
  --model claude-sonnet-4-6 \
  --profile quick
Set ANTHROPIC_API_KEY. Use --profile full for all 10 OWASP categories.
● OpenAI (GPT) 
argus scan \
  --target openai \
  --model gpt-4o \
  --profile compliance
Set OPENAI_API_KEY. Use --system-prompt to test a deployed persona.
● View Reports 
argus show \
  ./argus-reports/\
<session-id>.report.json
Reports also output as SARIF v2.1 for CI/CD integration and GRC handoff.
